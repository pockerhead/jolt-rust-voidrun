# `oxijolt-sys` — Jolt bindings via [joltc]
Unsafe bindings to [Jolt Physics] 5.6.0, generated by `bindgen` over joltc's `joltc.h` and this fork's
`native/joltc_ext/joltc_ext.h` (`JPH_*` names). joltc and Jolt are pinned submodules under `vendor/`; the
extension adds functions in joltc's naming (character state save/restore, character updates with explicit
filters and temp allocator) and is compiled into the joltc archive.

## Build Requirements
- A C++ toolchain (MSVC on Windows)
- CMake 3.20 or newer
- `libclang`, see the [bindgen guide](https://rust-lang.github.io/rust-bindgen/requirements.html) for installation steps.

Set `JOLTC_LIB_DIR` to a prebuilt install prefix (`lib/`, `include/joltc.h`, `include/joltc_ext.h`,
`oxijolt-sys-manifest.txt`) to
skip CMake. The prefix must match the target, C runtime, features and pinned commits; the build script
checks this.

## Features
- `asserts`: Compile Jolt with its debug assertions.
- `double-precision`: Enable higher precision simulation using doubles instead of floats.
- `cross-platform-deterministic`: Build Jolt with its cross-platform deterministic floating point settings.
